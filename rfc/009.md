---

## 1. 목표

### 1.1 범위

- VSCode 없이도 Webview UX를 단독 실행 가능하게 함
- Extension Host를 mock/stub으로 대체해도 프로토콜/상태 머신/렌더가 동일하게 동작하게 함
- fixture를 주입해 "모델 없이도" 모든 UX를 회귀 테스트할 수 있게 함

---

## 2. 구성

### 2.1 패키지 구조

| 경로 | 용도 |
|------|------|
| `apps/webview-dev/` | Webview UI를 브라우저에서 실행하는 dev 앱 |
| `packages/extension-host-mock/` | ToolPort를 구현하는 mock host |
| `packages/agent-runtime/` | orchestrator + contracts + gates가 여기서 동일하게 동작 |

### 2.2 Mock Extension Host 범위

**최소 구현 포트**

| 포트 | 설명 |
|------|------|
| workspace.read_file | |
| workspace.list_files | |
| search.rg_search | |
| workspace.apply_patch | in-memory 적용 |
| terminal.propose_command | 실행은 no-op 또는 fixture |
| workspace.diagnostics | fixture 제공 |

**옵션**

- git port는 fixture 기반 상태 머신으로 에뮬레이션 가능

---

## 3. Fixture 주입 설계

### 3.1 Fixture 타입

| 타입 | 설명 |
|------|------|
| **Workspace snapshot fixture** | 파일 트리 + 파일 내용 + diagnostics |
| **Agent event fixture** | AgentEvent[] 시퀀스 |
| **Model output fixture** | PlanIR/PatchIR/RunIR 스냅샷 |
| **Tool response fixture** | tool_call_id → response 매핑 |

### 3.2 주입 방식

- Dev app 시작 시 fixture를 로딩해 세션을 바로 구성
- Webview는 실제 메시지 버스 대신 **LocalBus**를 통해 runtime과 연결

---

## 4. LocalBus 프로토콜 고정

### 4.1 원칙

VSCode 환경과 **동일한 메시지 계약**을 사용해야 drift가 없음

- Webview ↔ Host 메시지 또한 `agent-protocol.v1`을 그대로 사용함
- dev 모드에서는 **transport만** 바꿈

### 4.2 Transport 비교

| 환경 | Transport |
|------|-----------|
| VSCode | postMessage |
| Dev | BroadcastChannel 또는 in-process emitter |

---

## 5. Gate

| Gate | 역할 |
|------|------|
| **gate-webview-standalone** | 동일 fixture로 VSCode 모드와 standalone 모드 렌더 결과가 동일함을 검증 |
| **gate-mock-host-parity** | tool-protocol 수준에서 mock host 응답이 스키마와 일치함을 검증 |
| **gate-fixture-replay** | event fixture replay로 end state가 동일함을 검증 |

## 8. 보완 및 참고

### 8.1 RFC-006과의 연계

- `pnpm dev:webview` ([RFC-006](006.md))는 본 RFC의 `apps/webview-dev`와 동일 진입점
- Fixture Builder ([RFC-006](006.md) 11절 tools/)가 본 RFC fixture-schema.v1.json 사용

### 8.2 LocalBus 구현 옵션

| 옵션 | 환경 | 용도 |
|------|------|------|
| BroadcastChannel | 브라우저 | webview-dev 단일 탭 |
| MessageChannel | in-process | Node.js + JSDOM 테스트 |
| EventEmitter | in-process | 단일 프로세스 dev 서버 |
