## 1. 목표

SOTA agent는 "한 번 잘 답함"이 아니라 **Analyze→Plan→Apply→Validate 전체 궤적이 회귀 가능**해야 함.

---

## 2. Trajectory Fixture

### 2.1 schemas/agent-ux/eval/trajectory-suite.v1.yaml

```yaml
cases:
  - id: refactor_unused_import
    workspace_fixture: fixtures/ws1
    user_prompt: "Remove unused imports"
    expected:
      tool_sequence:
        - workspace.read
        - patch.apply
      required_files_changed:
        - src/app.ts
      tests_pass: true
```

---

## 3. Evaluation Rules

**PASS 조건**:
- Tool sequence 형식 일치
- Patch 의미 일치
- Validation 성공
- **모델 문장 일치 불필요**

---

## 4. Recovery Trajectory

에러 발생 시:
1. error captured
2. recovery step 자동 생성
3. 성공적 수렴 시 PASS

---

## 7. SOTA+++ 체크리스트

아래가 충족되면 "AI agent SOTA 주장 가능" 수준. 상세: [RFC-015](015.md).

- [ ] Golden trajectory 회귀가 CI에 있음
- [ ] Provider 에러가 표준화되어 있음 (RFC-012)
- [ ] Partial replay 가능 (RFC-013)
- [ ] Cancel-safe 런타임 보장
