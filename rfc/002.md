## 1. 목표

React 19 + TanStack Virtual + (Jotai optional) 기반 **"1000 chars/sec 스트리밍에서도 안 얼어붙는 메시지 렌더러 뼈대"** 구현.

### 1.1 핵심 원칙 ([RFC-001](001.md) 준수)

- 전체 상태 스냅샷 금지
- DELTA_BATCH만 수신
- inputBuffer + 16ms commit
- virtualization 필수
- 대형 payload는 ref + lazy fetch
- UI commit/sec 상한 60

### 1.2 산출물

레포에 바로 넣고 시작 가능한 코드 세트.

## 3. 타입 정의 (types.ts)

Delta SSOT: [RFC-006 3절](006.md). Phase B 최소 세트.

```typescript
export type MessageId = string;

export type DiffRef = {
  ref: string;
  approx_bytes: number;
};

export type UiMessage = {
  id: MessageId;
  role: "user" | "assistant" | "system";
  created_at_ms: number;
  text: string;
  diff_ref?: DiffRef;
  diff_loaded?: string;
};

// Phase B 최소 Delta. 전체 세트는 [RFC-006](006.md) 3절 참조
export type Delta =
  | { t: "UPSERT_MESSAGE"; msg: UiMessage }
  | { t: "APPEND_TEXT"; id: MessageId; chunk: string }
  | { t: "SET_PROGRESS"; key: string; value: number }
  | { t: "SET_DIFF_LOADED"; id: MessageId; diff_text: string }
  | { t: "NOP" };

export type DeltaBatch = {
  type: "DELTA_BATCH";
  batch_id: string;
  created_at_ms: number;
  deltas: Delta[];
};
```

## 4. 정규화 Store (store.ts)

Jotai 없이 시작하는 기본 구조. 나중에 atom-per-item으로 확장 가능.

```typescript
import { useRef } from "react";
import { UiMessage } from "./types";

export type UiState = {
  messagesById: Record<string, UiMessage>;
  order: string[];
};

export function useNormalizedStore() {
  const stateRef = useRef<UiState>({
    messagesById: {},
    order: [],
  });

  const get = () => stateRef.current;

  const upsertMessage = (msg: UiMessage) => {
    const exists = !!stateRef.current.messagesById[msg.id];
    stateRef.current.messagesById[msg.id] = msg;
    if (!exists) stateRef.current.order.push(msg.id);
  };

  const appendText = (id: string, chunk: string) => {
    const m = stateRef.current.messagesById[id];
    if (!m) return;
    m.text += chunk;
  };

  return {
    get,
    upsertMessage,
    appendText,
  };
}
```

## 5. 스트리밍 버퍼 + 16ms Commit (streaming.ts)

성능의 핵심임.

```typescript
import { Delta } from "./types";

export function createStreamingEngine(
  applyBatch: (deltas: Delta[]) => void,
  markCommit?: () => void
) {
  const inputBuffer: Delta[] = [];
  let scheduled = false;

  function schedule() {
    if (scheduled) return;
    scheduled = true;

    requestAnimationFrame(() => {
      scheduled = false;
      if (!inputBuffer.length) return;

      const merged: Delta[] = coalesce(inputBuffer.splice(0));
      applyBatch(merged);
      markCommit?.();
    });
  }

  function push(deltas: Delta[]) {
    for (const d of deltas) inputBuffer.push(d);
    schedule();
  }

  return { push };
}

function coalesce(deltas: Delta[]): Delta[] {
  const out: Delta[] = [];
  const appendMap = new Map<string, string>();

  for (const d of deltas) {
    if (d.t === "APPEND_TEXT") {
      appendMap.set(d.id, (appendMap.get(d.id) ?? "") + d.chunk);
      continue;
    }
    out.push(d);
  }

  for (const [id, chunk] of appendMap) {
    out.push({ t: "APPEND_TEXT", id, chunk });
  }

  return out;
}
```

## 6. Virtualized List (virtualList.tsx)

```typescript
import { useRef } from "react";
import { useVirtualizer } from "@tanstack/react-virtual";
import { UiState } from "./store";

type Props = {
  state: UiState;
  onExpandDiff: (id: string) => void;
};

export function VirtualMessageList({ state, onExpandDiff }: Props) {
  const parentRef = useRef<HTMLDivElement | null>(null);

  const rowVirtualizer = useVirtualizer({
    count: state.order.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 88,
    overscan: 12,
  });

  const items = rowVirtualizer.getVirtualItems();

  return (
    <div ref={parentRef} style={{ height: "100%", overflow: "auto" }}>
      <div
        style={{
          height: rowVirtualizer.getTotalSize(),
          position: "relative",
        }}
      >
        {items.map((virtualRow) => {
          const id = state.order[virtualRow.index];
          const msg = state.messagesById[id];

          return (
            <div
              key={id}
              style={{
                position: "absolute",
                top: 0,
                left: 0,
                width: "100%",
                transform: `translateY(${virtualRow.start}px)`,
              }}
              className="border-b px-3 py-2"
            >
              <div className="text-xs opacity-60">{msg.role}</div>
              <div className="whitespace-pre-wrap text-sm">{msg.text}</div>

              {msg.diff_ref && (
                <>
                  <button
                    className="mt-2 text-sm border px-2 py-1 rounded"
                    onClick={() => onExpandDiff(id)}
                  >
                    load diff
                  </button>

                  {msg.diff_loaded && (
                    <pre className="mt-2 text-xs max-h-80 overflow-auto border p-2">
                      {msg.diff_loaded}
                    </pre>
                  )}
                </>
              )}
            </div>
          );
        })}
      </div>
    </div>
  );
}
```

## 7. App.tsx (메인)

```typescript
import React, { useEffect, useState } from "react";
import { useNormalizedStore } from "./store";
import { createStreamingEngine } from "./streaming";
import { VirtualMessageList } from "./virtualList";
import { DeltaBatch } from "./types";

declare const acquireVsCodeApi: any;

export default function App() {
  const vscode = acquireVsCodeApi?.();
  const store = useNormalizedStore();

  const [, forceRender] = useState(0);

  const streaming = React.useMemo(
    () =>
      createStreamingEngine((batch) => {
        for (const d of batch) {
          if (d.t === "UPSERT_MESSAGE") store.upsertMessage(d.msg);
          if (d.t === "APPEND_TEXT") store.appendText(d.id, d.chunk);
        }
        forceRender((x) => x + 1);
      }),
    []
  );

  useEffect(() => {
    const handler = (ev: MessageEvent) => {
      const msg = ev.data;
      if (!msg) return;

      if (msg.type === "DELTA_BATCH") {
        const batch = msg as DeltaBatch;
        streaming.push(batch.deltas);
      }
    };

    window.addEventListener("message", handler);
    return () => window.removeEventListener("message", handler);
  }, []);

  const handleExpandDiff = async (id: string) => {
    vscode?.postMessage({
      type: "TOOL_CALL",
      tool: "workspace.get_blob",
      id,
    });
  };

  return (
    <div className="h-screen flex flex-col">
      <header className="px-3 py-2 border-b font-semibold">
        Agent UX
      </header>

      <main className="flex-1">
        <VirtualMessageList
          state={store.get()}
          onExpandDiff={handleExpandDiff}
        />
      </main>
    </div>
  );
}
```

## 8. SOTA++ 성능이 나오는 이유

| 항목 | 동작 |
|------|------|
| 초당 1000자 | UI commit은 최대 60회, APPEND_TEXT는 프레임 내 coalesce |
| 메시지 10,000개+ | DOM에는 20~40개만 존재 (virtualization) |
| 대형 diff 수 MB | ref로 분리, 펼칠 때만 로드 |
| 전체 AgentState | 절대 전송하지 않음 |
