| 항목 | 값 |
|------|-----|

## 1. 목표

### 1.1 산출물

[RFC-002](002.md)의 React 19 + TanStack Virtual 기반 렌더러를 **Jotai atom-per-message** 구조로 업그레이드하고, **perfCollector**까지 붙여서 "1000 chars/sec 스트리밍에서도 안 얼어붙는" 뼈대를 완성함.

### 1.2 핵심 변화

| 항목 | RFC-002 | RFC-003 |
|------|---------|---------|
| 렌더 | 전체 forceRender | 해당 메시지 Row만 리렌더 |
| 스트리밍 | inputBuffer → rAF → store | inputBuffer → rAF → coalesce → atom 업데이트 |
| 성능 측정 | 없음 | postMessage rx/sec, ui commit/sec, long task, frame budget |

## 3. 타입 (types.ts)

Delta SSOT: [RFC-006 3절](006.md). SET_DIFF_LOADED 포함.

```typescript
export type MessageId = string;

export type DiffRef = {
  ref: string;
  approx_bytes: number;
};

export type UiMessage = {
  id: MessageId;
  role: "user" | "assistant" | "system";
  created_at_ms: number;
  text: string;
  diff_ref?: DiffRef;
  diff_loaded?: string;
};

export type Delta =
  | { t: "UPSERT_MESSAGE"; msg: UiMessage }
  | { t: "APPEND_TEXT"; id: MessageId; chunk: string }
  | { t: "SET_PROGRESS"; key: string; value: number }
  | { t: "SET_DIFF_LOADED"; id: MessageId; diff_text: string }
  | { t: "NOP" };

export type DeltaBatch = {
  type: "DELTA_BATCH";
  batch_id: string;
  created_at_ms: number;
  deltas: Delta[];
};
```

## 4. Jotai Store (jotaiStore.ts)

### 4.1 설계

- `orderAtom`: 메시지 ID 배열
- `messageAtomFamily(id)`: 메시지 1개 상태 atom
- write atom으로 upsert/append를 "정해진 방식"으로만 수행

```typescript
import { atom } from "jotai";
import { atomFamily } from "jotai/utils";
import type { MessageId, UiMessage } from "./types";

export const orderAtom = atom<MessageId[]>([]);

export const messageAtomFamily = atomFamily((id: MessageId) =>
  atom<UiMessage | null>(null)
);

export const upsertMessageAtom = atom(
  null,
  (get, set, msg: UiMessage) => {
    const current = get(messageAtomFamily(msg.id));
    const exists = current != null;

    set(messageAtomFamily(msg.id), msg);

    if (!exists) {
      const order = get(orderAtom);
      set(orderAtom, [...order, msg.id]);
    }
  }
);

export const appendTextAtom = atom(
  null,
  (get, set, args: { id: MessageId; chunk: string }) => {
    const m = get(messageAtomFamily(args.id));
    if (!m) return;
    if (!args.chunk) return;

    set(messageAtomFamily(args.id), { ...m, text: m.text + args.chunk });
  }
);

export const setDiffLoadedAtom = atom(
  null,
  (get, set, args: { id: MessageId; diff_text: string }) => {
    const m = get(messageAtomFamily(args.id));
    if (!m) return;
    set(messageAtomFamily(args.id), { ...m, diff_loaded: args.diff_text });
  }
);
```

## 5. 스트리밍 엔진 (streaming.ts)

### 5.1 목표

- postMessage 수신은 push만
- commit은 rAF에서 1회
- 같은 messageId APPEND_TEXT는 프레임 내 coalesce

```typescript
import type { Delta } from "./types";

export function createStreamingEngine(opts: {
  applyBatch: (deltas: Delta[]) => void;
  markCommit?: () => void;
}) {
  const inputBuffer: Delta[] = [];
  let scheduled = false;

  function schedule() {
    if (scheduled) return;
    scheduled = true;

    requestAnimationFrame(() => {
      scheduled = false;
      if (!inputBuffer.length) return;

      const batch = inputBuffer.splice(0, inputBuffer.length);
      const merged = coalesce(batch);
      opts.applyBatch(merged);
      opts.markCommit?.();
    });
  }

  function push(deltas: Delta[]) {
    for (const d of deltas) inputBuffer.push(d);
    schedule();
  }

  return { push };
}

function coalesce(deltas: Delta[]): Delta[] {
  const out: Delta[] = [];
  const appendMap = new Map<string, string>();

  for (const d of deltas) {
    if (d.t === "APPEND_TEXT") {
      appendMap.set(d.id, (appendMap.get(d.id) ?? "") + d.chunk);
      continue;
    }
    out.push(d);
  }

  for (const [id, chunk] of appendMap) {
    out.push({ t: "APPEND_TEXT", id, chunk });
  }

  return out;
}
```

## 6. perfCollector (perfCollector.ts)

### 6.1 수집 항목

| 항목 | 설명 |
|------|------|
| INP 유사값 | interactionStart → next rAF까지 |
| long task count | 50ms 이상 (가능한 환경에서) |
| frame dt 샘플 | 16ms/32ms 초과 비율 |

## 7. MessageRow.tsx

Row는 해당 id atom만 구독. 텍스트가 늘어도 그 Row만 리렌더.

```typescript
import React from "react";
import { useAtomValue } from "jotai";
import type { MessageId } from "./types";
import { messageAtomFamily } from "./jotaiStore";

export function MessageRow(props: {
  id: MessageId;
  style: React.CSSProperties;
  onExpandDiff: (id: MessageId) => void;
}) {
  const msg = useAtomValue(messageAtomFamily(props.id));

  if (!msg) {
    return (
      <div style={props.style} className="border-b px-3 py-2 opacity-60">
        missing message
      </div>
    );
  }

  return (
    <div style={props.style} className="border-b px-3 py-2">
      <div className="text-xs opacity-60">{msg.role}</div>
      <div className="whitespace-pre-wrap text-sm">{msg.text}</div>

      {msg.diff_ref && (
        <>
          <button
            className="mt-2 text-sm border px-2 py-1 rounded"
            onClick={() => props.onExpandDiff(msg.id)}
          >
            load diff
          </button>

          {msg.diff_loaded && (
            <pre className="mt-2 text-xs max-h-80 overflow-auto border p-2 whitespace-pre-wrap">
              {msg.diff_loaded}
            </pre>
          )}
        </>
      )}
    </div>
  );
}
```

## 8. VirtualMessageList.tsx

- 리스트는 `orderAtom`만 구독
- Row는 `messageAtomFamily(id)`만 구독

```typescript
import React from "react";
import { useAtomValue } from "jotai";
import { useVirtualizer } from "@tanstack/react-virtual";
import { orderAtom } from "./jotaiStore";
import type { MessageId } from "./types";
import { MessageRow } from "./MessageRow";

export function VirtualMessageList(props: { onExpandDiff: (id: MessageId) => void }) {
  const order = useAtomValue(orderAtom);
  const parentRef = React.useRef<HTMLDivElement | null>(null);

  const rowVirtualizer = useVirtualizer({
    count: order.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 88,
    overscan: 12,
  });

  const items = rowVirtualizer.getVirtualItems();

  return (
    <div ref={parentRef} style={{ height: "100%", overflow: "auto" }}>
      <div style={{ height: rowVirtualizer.getTotalSize(), position: "relative" }}>
        {items.map((v) => {
          const id = order[v.index];
          return (
            <MessageRow
              key={id}
              id={id}
              style={{
                position: "absolute",
                top: 0,
                left: 0,
                width: "100%",
                transform: `translateY(${v.start}px)`,
              }}
              onExpandDiff={props.onExpandDiff}
            />
          );
        })}
      </div>
    </div>
  );
}
```

## 9. App.tsx

### 9.1 포인트

- postMessage 수신 시 `perf.markPostMessageRx`
- DELTA_BATCH만 받아 `streaming.push`
- streaming commit 시 `perf.markUiCommit`
- applyBatch는 Jotai write atoms로만 반영
- TOOL_RESULT(workspace.get_blob) → SET_DIFF_LOADED Delta로 변환
- perf는 `window.__perf`로 노출

### 9.2 핵심 코드

```typescript
// applyBatch: Jotai write atoms 사용
applyBatch: (batch: Delta[]) => {
  for (const d of batch) {
    if (d.t === "UPSERT_MESSAGE") upsert(d.msg);
    if (d.t === "APPEND_TEXT") append({ id: d.id, chunk: d.chunk });
    if (d.t === "SET_DIFF_LOADED") setDiffLoaded({ id: d.id, diff_text: d.diff_text });
  }
},
markCommit: () => perf.markUiCommit(),

// TOOL_RESULT 처리
if (msg.type === "TOOL_RESULT" && msg.tool === "workspace.get_blob") {
  streaming.push([{ t: "SET_DIFF_LOADED", id: msg.id, diff_text: msg.text }]);
}
```

## 10. 테스트용 스트리밍 인젝터 (선택)

Extension Host 붙기 전에 Webview 단독으로 1000 chars/sec 스트리밍을 검증하기 위한 dev-only 함수.

```typescript
export function installDevInjector(pushDeltaBatch: (batch: any) => void) {
  (window as any).__dev = {
    stream1000cps: (seconds: number) => {
      const id = "m1";
      pushDeltaBatch({
        type: "DELTA_BATCH",
        batch_id: crypto.randomUUID(),
        created_at_ms: Date.now(),
        deltas: [
          { t: "UPSERT_MESSAGE", msg: { id, role: "assistant", created_at_ms: Date.now(), text: "" } },
        ],
      });

      const rate = 1000;
      const tickMs = 16;
      const charsPerTick = Math.floor((rate * tickMs) / 1000);

      let elapsed = 0;
      const timer = setInterval(() => {
        elapsed += tickMs;
        const chunk = "x".repeat(charsPerTick);

        pushDeltaBatch({
          type: "DELTA_BATCH",
          batch_id: crypto.randomUUID(),
          created_at_ms: Date.now(),
          deltas: [{ t: "APPEND_TEXT", id, chunk }],
        });

        if (elapsed >= seconds * 1000) clearInterval(timer);
      }, tickMs);
    },
  };
}
```

## 11. SOTA++ 성능이 나오는 이유

### 11.1 렌더 범위 절단

- 리스트는 orderAtom만 변경 시 리렌더
- 메시지 텍스트는 해당 message atom만 변경
- 가상 스크롤로 DOM 상한 유지

### 11.2 스트리밍 안정화

- postMessage는 자주 와도 inputBuffer에만 적재
- UI commit은 rAF에서 1회
- APPEND_TEXT는 프레임 내 합쳐서 atom 업데이트 횟수 최소화

### 11.3 Gate 연결 준비

- `window.__perf.reset()`
- `window.__perf.snapshot()`
