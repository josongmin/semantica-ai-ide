# RFC-013: IR v2 Execution Contract

| 항목 | 값 |
|------|-----|
| 상태 | Draft |
| 작성일 | 2026-03 |
| 선행 | RFC-000, RFC-006 |
| SOTA++ | v1 |

---

## 1. 목표

IR은 "출력 포맷"이 아니라 **실행 가능한 계약(Execution Contract)**임.

---

## 2. PlanIR v2

### 2.1 schemas/agent-ux/ir/plan-ir.v2.json

```json
{
  "plan_id": "string",
  "steps": [
    {
      "step_id": "string",
      "title": "string",
      "preconditions": [],
      "postconditions": [],
      "required_context_refs": [],
      "tool": "optional",
      "risk_level": "LOW|MEDIUM|HIGH"
    }
  ]
}
```

**특징**:
- Step 단위 재실행 가능
- Pre/Post 조건 명시
- risk_level → 승인 정책과 연결

---

## 3. PatchIR v2 (Reversible)

### 3.1 schemas/agent-ux/ir/patch-ir.v2.json

```json
{
  "patch_id": "string",
  "affected_files": [],
  "diff": "string",
  "reversible": true,
  "revert_diff": "string"
}
```

**원칙**:
- 모든 patch는 revert 가능
- revert 없는 patch는 승인 불가

---

## 4. RunIR v2

### 4.1 schemas/agent-ux/ir/run-ir.v2.json

```json
{
  "run_id": "string",
  "command": "string",
  "approval_required": true,
  "expected_outputs": []
}
```

---

## 5. Execution Properties

| 속성 | 설명 |
|------|------|
| **idempotency** | tool metadata에 명시 |
| **interrupt-safe** | cancel token 지원 |
| **partial replay** | 부분 재실행 가능 |

---

## 6. Gate 추가

| Gate | 역할 |
|------|------|
| gate-ir-replay-determinism | IR 재실행 시 결과 일치 |
| gate-patch-revert-valid | 모든 patch에 revert_diff 존재 |
| gate-step-partial-execution | Step 단위 부분 실행 검증 |

---

## 7. SSOT 확장 ([RFC-006](006.md) 2절)
