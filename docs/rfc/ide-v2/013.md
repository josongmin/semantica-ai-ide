1. Summary

이 문서는 DevOS에서 모든 객체의 Identity와 Federation 모델을 고정하는 SSOT다.

DevOS는 다음 환경을 지원해야 한다.

multi repo
multi user
multi agent
multi runtime
multi client

이를 위해 모든 시스템 객체는 workspace identity에 귀속된다.

12. Federation Rules
    Rule 1

모든 객체는 workspace에 귀속된다.

Rule 2

repo는 독립적으로 관리된다.

Rule 3

query는 repo 단위가 아니라 workspace context로 실행된다.

Rule 4

agent는 session 범위에서 실행된다.
