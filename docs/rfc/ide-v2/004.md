2. Problem Statement

현재 대부분 개발 환경은 시간 축을 거의 제공하지 않는다.

Tool Temporal Capability
Git commit history
IDE undo/redo
CI pipeline logs

문제:

문제 설명
agent reasoning 사라짐 실행 과정 추적 불가
analysis 상태 재현 어려움 replay 불가
debug context 손실 history 부족
review 과정 추적 불가 evidence 단절

AI-native 개발 환경에서는 temporal visibility가 필수다.

3. Goals

Temporal Surface는 다음 기능을 제공한다.

3.1 Execution Timeline

agent / analysis / review 이벤트를 timeline으로 표시

3.2 State Replay

과거 상태로 IDE를 재구성

3.3 Checkpoint System

중요 상태를 snapshot으로 저장

3.4 Patch Lineage

patch evolution 추적
