1. Summary

Semantica IDE의 Code Review는 단순 Diff 기반 리뷰가 아니라 Evidence 기반 리뷰이다.

기존 IDE 리뷰:

diff

- comment

Semantica 리뷰:

diff

- impact analysis
- security delta
- clone delta
- complexity delta
- test impact
- proof explanation

즉 Review Surface는 Patch Courtroom 역할을 한다.

2. 문제 정의

현재 대부분 코드 리뷰 도구는 아래 수준이다.

도구 특징
GitHub diff + comment
GitLab diff + pipeline
Cursor diff + AI reasoning

문제:

문제 설명
impact 모름 수정 영향 불명
security 모름 취약점 여부 불명
complexity 모름 코드 품질 변화 불명
proof 없음 reasoning 신뢰 어려움

Semantica는 이미 아래 분석을 갖고 있다.

impact analysis

taint analysis

clone detection

metrics

slicing

proof DAG

하지만 UI surface가 없으면 엔진 강점이 사용자에게 보이지 않는다.

3. 목표

Review Surface는 다음을 제공해야 한다.

15. 결론

Review Surface는 Semantica IDE의 핵심 UX다.

엔진의 분석 결과를 사용자가 이해 가능한 형태로 보여주는 가장 중요한 surface이다.
