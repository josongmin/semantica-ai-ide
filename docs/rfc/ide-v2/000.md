1. Summary

Semantica IDE는 단순 코드 에디터가 아니라 DevOS Shell 구조를 가진다.

Editor Shell은 다음 역할을 가진다.

여러 surface를 하나의 작업 환경으로 조합

분석 결과를 editor 중심으로 시각화

agent / review / replay / findings 같은 고차 기능을 독립 패널로 제공

기능이 계속 추가되어도 레이아웃 구조가 깨지지 않게 유지

Editor Shell은 Integration Kernel 위에서만 동작한다.

2-1. Editor-centric Architecture

IDE의 중심은 항상 Editor Surface다.

다른 모든 surface는 editor context에 종속된다.

예:

Surface Editor와의 관계
Hover cursor 기반
References symbol 기반
Impact file + symbol 기반
Slice location 기반
Findings file 기반
Review diff 기반
2-2. Surface-based Layout

Semantica IDE는 아래 6개의 UI Surface로 구성된다 (RFC-009, RFC-012 참조).

Editor Surface (RFC-002)
Review Evidence Surface (RFC-004)
Temporal Replay Surface (RFC-005)
Agent Workspace Surface (RFC-006)
Repository Knowledge Graph Surface (RFC-007)
Multi-Agent Orchestrator Surface (RFC-008)

주의: 기존 Runtime Surface는 RFC-014(Runtime Abstraction)에 흡수됨.

각 surface는 독립 패널로 존재하며 Shell이 이를 조합한다.

Editor Shell의 목적은 코드를 보여주는 것이 아니다.

Semantica IDE의 목적은

코드

- 분석
- 증거
- 시간축

을 하나의 작업 환경으로 결합하는 것이다.

따라서 Editor Shell은 단순 IDE UI가 아니라 Analysis-Native DevOS Shell로 설계된다.
