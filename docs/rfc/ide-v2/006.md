1. Summary

Agent Workspace Surface는 AI Agent 작업을 관리하는 전용 IDE Surface다.

기존 IDE

user → code edit → commit

AI-native IDE

user
↓
agent plan
↓
agent execution
↓
analysis
↓
review
↓
patch

Agent Workspace는 이 과정을 시각화하고 제어하는 공간이다.

2. Problem Statement

현재 AI coding tools

Tool Agent Visibility

Devin task log
Copilot 거의 없음

문제

문제 설명

5. Agent Model

Agent Workspace의 agent 모델은 RFC-008-V2(Multi-Agent Orchestrator)의 AgentUnit을 canonical model로 사용한다.

5.1 AgentUnit (canonical — RFC-008-V2)
interface AgentUnit {
  id: string
  role: "planner" | "search" | "impact" | "patch" | "test" | "review" | "repair"
  name: string
  status: "idle" | "assigned" | "running" | "waiting" | "blocked" | "failed" | "completed"
  currentTaskId?: string
  currentStep?: string
  progress?: number
}
5.2 AgentStep
interface AgentStep {
  id: string
  type: string
  status: string
}

8. Task Board

Agent tasks는 Kanban 형태로 표시된다.

상태 설명
Queued 대기
Running 실행
Completed 완료
Failed 실패
9. Context Inspector

Agent context를 확인할 수 있다.

예

항목 내용
Files 입력 파일
Symbols 관련 심볼
Tests 영향 테스트
Constraints 정책
10. Agent Controls

사용자는 agent 실행을 제어할 수 있다.

Action 설명
pause 실행 중지
resume 재개
cancel 취소
approve 승인
11. Multi-Agent Support

Semantica는 multi-agent 작업을 지원한다.

예

Agent A → code search
Agent B → impact analysis
Agent C → patch generation
12. Event Integration

Agent Workspace는 Event Bridge로 상태를 받는다.

이벤트 모델은 RFC-002-V2의 workspace-aware DevOSEvent를 canonical 구조로 사용한다.

예

Event 설명
agent_run_started 실행 시작
agent_step_started step 시작
agent_step_completed step 완료
agent_failed 실패
